# Video to particles

Как уложить анимацию выигрыша для слота на Pixi 8 (игра на 60 fps, в основном мобильные игроки) в минимум мегабайт и видеопамяти. Здесь сравниваются AVIF-секвенция, тайл-дельты, видео, WebCodecs и частицы в реальном времени — на синтетических анимациях и на настоящем ролике из генератора «Монета в огне».

## Итог

- **Полноэкранный эффект из генератора** (огонь, дым, движение камеры) оставлять видео как есть: 0,99 МБ против 3,97 МБ у AVIF-секвенции и 1,9 МБ видеопамяти против 226 МБ. Если нужен покадровый контроль, тот же поток H.264 можно играть через WebCodecs прямо в текстуру Pixi.
- **Эффект, который собирается из частиц**: одна картинка символа и код — 0,05 МБ и около 2 МБ видеопамяти, длина не ограничена.
- **Тайл-дельты** окупаются только на локальных эффектах поверх неподвижного символа на прозрачном фоне: ×4,8 на искрах. На полноэкранном огне они тяжелее обычной секвенции, и чёрный или прозрачный фон этого не меняет.

## Что внутри

| Папка | Что там |
|---|---|
| `fire-coin-win/` | Модуль `FireCoinWin` для Pixi 8 и демо «видео против частиц»: сверху ролик, ниже тот же выигрыш на частицах, внизу код |
| `packing-bench/` | Демо-бенчмарк: AVIF-секвенция, тайл-дельты, видео и WebCodecs на четырёх анимациях; кнопка «Замерить» меряет на твоём устройстве |
| `tools/` | Скрипты генерации, кодирования и проверки |
| `results/` | Сырые результаты замеров в JSON |

## Запуск демо

Страницы загружают файлы через `fetch`, поэтому нужен любой статический сервер:

```sh
npx http-server -p 8080 -c-1 .
```

Затем открыть `http://localhost:8080/fire-coin-win/` и `http://localhost:8080/packing-bench/`. Pixi 8.22 подключается с jsDelivr.

## Модуль FireCoinWin

`fire-coin-win/fire-coin-win.js`, 17 КБ (6 КБ в gzip). Символ неподвижен, вокруг него огненное кольцо, взрыв искр, ударные волны, горящий край, блик и лучи. Все текстуры частиц рисуются кодом при первом создании и общие для всех экземпляров.

```js
import { Assets } from 'pixi.js';
import { FireCoinWin } from './fire-coin-win.js';

const coin = await Assets.load('coin.avif');      // круглый символ с прозрачным фоном

const fx = new FireCoinWin({ coin, diameter: 400, density: 1 });
fx.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(fx);

fx.warmUp(1);                                      // огненное кольцо горит уже на первом кадре
app.ticker.add((ticker) => fx.update(ticker.deltaMS / 1000));

fx.play();                                         // выпал выигрыш
// fx.destroy();                                   // символ ушёл с экрана
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `coin` | — | Текстура символа |
| `diameter` | 400 | Диаметр символа в пикселях сцены; под него масштабируется весь эффект |
| `density` | 1 | Множитель частиц: 0,5 экономно, 2 максимум; можно менять на лету |
| `loop` | false | Повторять выигрыш каждые 4,2 с |
| `embers` | true | Угольки, поднимающиеся вокруг символа |
| `seed` | 7 | Зерно случайности: каждый `play()` выглядит одинаково |

Эффект рисует символ сам, поэтому исходный спрайт символа на время выигрыша нужно прятать. Проверено на Pixi 8.22. Для Pixi 7 нужна адаптация: там другой `ParticleContainer`.

## Результаты

Качество везде сверено по PSNR с исходными кадрами, сравнение при одинаковом качестве.

### Синтетика: 512×512, 2 с, 60 fps (120 кадров)

| Анимация | Изменено тайлов | AVIF-секвенция | Тайл-дельты | Видео H.264, stacked alpha |
|---|---|---|---|---|
| Искры | 10% | 3,22 МБ | 0,67 МБ | 0,17 МБ |
| Блик и свечение | 49% | 3,71 МБ | 1,74 МБ | 0,38 МБ |
| Прыжок | 62% | 2,97 МБ | 1,98 МБ | 0,79 МБ |

Видеопамять: секвенция 120 МБ, тайл-дельты 17,5 / 47,4 / 49,9 МБ, видео 2 МБ.

### «Монета в огне»: 692×720, 24 fps, 5 с

В игре на 60 fps это 300 тиков, из них 119 уникальных кадров.

| Упаковка | Вес | Видеопамять |
|---|---|---|
| Видео из генератора, без звука | **0,99 МБ** | 1,9 МБ |
| AVIF-секвенция, 119 уникальных кадров | 3,97 МБ | 226 МБ |
| AVIF-секвенция «как есть» на 60 fps, 300 кадров | 9,96 МБ | 570 МБ |
| Тайл-дельты, лучший вариант (тайл 64) | 4,61 МБ | 230 МБ |
| PNG-секвенция | 47,9 МБ | 226 МБ |

### Тот же ролик с чёрным и прозрачным фоном

| Версия | AVIF-секвенция | Тайл-дельты | Изменено тайлов |
|---|---|---|---|
| С барабанами (исходный) | 3,97 МБ | 4,61 МБ | 82% |
| Чёрный фон, чистый рендер | 3,93 МБ | 4,69 МБ | 79% |
| Чёрный фон, как отдаст генератор в mp4 | 3,77 МБ | 4,66 МБ | 78% |
| Прозрачный фон | 7,57 МБ | 8,81 МБ | 80% |

### Попытки сделать меньше AVIF-секвенции на чёрном фоне

| Способ | Вес | Качество |
|---|---|---|
| AVIF-секвенция, q70, speed 6 | 3,93 МБ | 40,4 дБ |
| То же, speed 2 (медленный кодер) | 3,61 МБ | 40,6 дБ |
| Свой кодек: векторы движения блоков + остаток в AVIF | 5,15 МБ | 35,9 дБ |
| AV1-видео (SVT-AV1, crf 20) | 2,61 МБ | 39,0 дБ |
| Поток H.264 из генератора через WebCodecs | 1,04 МБ | исходный |

Огонь от кадра к кадру почти непредсказуем, поэтому межкадровое предсказание почти ничего не даёт. Генератор уже сжал ролик лучше, чем получится при перекодировании.

### Частицы

| Вариант | Скачать | Видеопамять | Длина |
|---|---|---|---|
| Символ + модуль `FireCoinWin` | 0,05 МБ | ≈2 МБ | без ограничений |
| Ролик из генератора, mp4 | 0,99 МБ | 1,9 МБ | 5 с |
| Тот же ролик AVIF-секвенцией | 3,97 МБ | 226 МБ | 5 с |

Симуляция на десктопе: 0,2–0,45 мс на кадр при пике около 1 800 частиц. Основная нагрузка на GPU — наложение аддитивных слоёв. Реальные fps на телефоне показывает счётчик в углу демо.

## Как воспроизвести

Нужны Python 3.11+, Node 20+ и ffmpeg с libx264, libvpx-vp9 и libsvtav1.

```sh
pip install -r requirements.txt
npm install

# синтетика
python3 tools/gen_frames.py work/frames
python3 tools/encode.py work/frames work/out 70

# ролик: кадры и их время
mkdir -p work/gem/frames
cp fire-coin-win/clip.mp4 work/gem/src.mp4
ffmpeg -i work/gem/src.mp4 -vsync passthrough work/gem/frames/%04d.png
ffprobe -v error -select_streams v -show_entries frame=pts_time -of csv=p=0 work/gem/src.mp4 | tr -d ',' > work/gem/pts.txt
python3 tools/encode_clip.py work/gem/frames work/gem/pts.txt work/gem/src.mp4 work/gem/out

# чёрный и прозрачный фон
python3 tools/key_clip.py work/gem/frames work/gem/keyed
python3 tools/encode_clip.py work/gem/keyed/black work/gem/pts.txt work/gem/keyed/black_src.mp4 work/gem/keyed/out_black

# пересобрать демо «видео против частиц» после правки модуля
python3 tools/build_vs.py

# проверить страницы в headless Chromium
node tools/vs_check.mjs
QUICK=1 node tools/harness.mjs
```

| Скрипт | Что делает |
|---|---|
| `gen_frames.py` | Три синтетические анимации символа |
| `encode.py`, `tune_video.py` | Секвенция, тайл-дельты и видео для синтетики, подбор CRF видео |
| `encode_clip.py`, `clip_delta_write.py` | То же для ролика с картой тиков 60 Гц, запись выбранного варианта тайл-дельт |
| `key_clip.py` | Версии ролика с чёрным и прозрачным фоном |
| `ceiling.py`, `rd_sweep.py` | Потолок сжатия: медленный AVIF, AV1, уменьшение, шумоподавление |
| `mc_encode.py` | Свой кодек с компенсацией движения (не выиграл у секвенции) |
| `wc_extract.py` | Индекс кадров mp4 для WebCodecs |
| `build_page.py`, `page_script.html` | Сборка `packing-bench` |
| `build_vs.py`, `htmldoc.py` | Сборка `fire-coin-win/index.html` из `page.tpl.html` и модуля |
| `harness.mjs`, `vs_check.mjs` | Проверка страниц и замеры в headless Chromium |
